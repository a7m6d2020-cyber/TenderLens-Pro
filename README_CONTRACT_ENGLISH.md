# 📜 مُدرّس الإنجليزية التعاقدية — Contract English Tutor

تطبيق تفاعلي يُعلّمك **الإنجليزية التعاقدية (Legal/Contract English)** باحتراف،
حتى تقرأ عقود **الفيديك (FIDIC)** وغيرها بالإنجليزية مباشرةً **دون الحاجة إلى ترجمة**.

مصمَّم خصيصاً للمتحدثين بالعربية في مجال المقاولات والعقود الهندسية (الخليج/السعودية).

---

## ✨ لماذا هذا التطبيق؟

قراءة عقود الفيديك بالإنجليزية تتطلب أكثر من «معرفة الإنجليزية»: تتطلب إتقان
**لغة قانونية** لها مفرداتها وصيغها (`shall` / `notwithstanding` / `thereof`)
وكلماتٍ عادية بمعانٍ خاصة (`Plant` = التجهيزات الآلية، لا «النبات»!).
يبني هذا التطبيق هذه المَلَكة طبقةً فوق طبقة بأفضل تقنيات التعلّم المثبتة علمياً.

---

## 🧠 المنهجية التعليمية

| التقنية | التطبيق العملي داخل البرنامج |
|---|---|
| **التكرار المتباعد (Spaced Repetition – Leitner)** | بطاقات تُعيد عرض المصطلح قبيل نسيانه، فيثبت الحفظ بأقل جهد |
| **الاستدعاء النشط (Active Recall)** | تستحضر المعنى من ذاكرتك قبل كشفه، واختبارات بعد كل درس |
| **المدخل المفهوم (Comprehensible Input – i+1)** | نصوص فيديك متدرّجة الصعوبة مع مسرد تفاعلي يُكشف عند الحاجة |
| **التلقين الصوتي + المحاكاة (Audio & Shadowing)** | نطق المتصفح يُسمعك الكلمة/الجملة بلهجة بريطانية أو أمريكية، وتكرّرها خلفه |
| **الأزواج الصغرى (Minimal Pairs)** | تدريبات `P/B` و `V/F` والنبر الخاصة بصعوبات المتحدث العربي |
| **التعلّم بالسياق (Chunking & Collocations)** | كل مصطلح داخل جملة عقدية حقيقية مع متلازماته اللفظية |

> النطق يعمل عبر **Web Speech API** المدمج في المتصفح — لا يحتاج أي مفتاح API أو خدمة خارجية.
> يُفضّل استخدام متصفح **Chrome / Edge** للحصول على أفضل الأصوات.

---

## 🗂️ أقسام التطبيق

1. **🏠 الرئيسية** — لوحة تقدّمك وخطة اليوم.
2. **📚 الدروس** — منهج متدرّج (9 دروس): من بنية الجملة التعاقدية وأفعال الإلزام
   (`shall/may`) وعائلات `here-/there-`، إلى تشريح بنود فيديك كاملة ولغة المطالبات والإنهاء والتحكيم.
3. **🗂️ البطاقات والحفظ** — بطاقات بنظام Leitner للتكرار المتباعد.
4. **🔊 النطق واللهجة** — مختبر نطق: تحديات العربي الصوتية + نطق كل مصطلح مع تقطيع مقاطعه ونبره.
5. **📖 معمل القراءة** — بنود بأسلوب الفيديك (ضمان حسن التنفيذ، غرامات التأخير، القوة القاهرة...)
   مع مسرد تفاعلي وترجمة قابلة للإخفاء وأسئلة استيعاب.
6. **💬 المحادثات** — حوارات مهنية منطوقة (اجتماع موقع، تفاوض على تغيير، نزاع وإحالة للمجلس).
7. **📝 الاختبارات** — مطابقة المصطلحات، اختبار النطق/التقطيع، وأسئلة الدروس المجمّعة.
8. **🔎 المعجم** — قاموس قابل للبحث لأكثر من 70 مصطلحاً تعاقدياً مع النطق والتعريف والمثال.
9. **📈 تقدّمي** — إحصاءاتك، توزيع البطاقات على الصناديق، وتصدير/استيراد تقدّمك.

## 📚 المحتوى

- **73** مصطلحاً تعاقدياً عبر **10 تصنيفات** (أطراف العقد، الوثائق، الوقت، الدفع،
  التغييرات والمطالبات، المخاطر، الجودة، الإنهاء، المنازعات، واللغة القانونية الأساسية).
- **9 دروس** منهجية مع اختبارات.
- **4 نصوص قراءة** بأسلوب الفيديك مع مسرد وترجمة.
- **3 محادثات** مهنية بمسرد ونصائح.
- **6 تحديات نطق** مع جمل تدريب.

كل المحتوى في `contract_english_data.py` — يسهل التوسيع بإضافة عناصر جديدة.

## 🚀 التشغيل

```bash
pip install -r requirements_tutor.txt
streamlit run contract_english_tutor.py
```

ثم افتح المتصفح على العنوان الذي يظهر (عادةً http://localhost:8501).

> **ملاحظة:** تقدّمك يُحفظ محلياً في `.tutor_progress.json`. في البيئات السحابية المؤقتة
> قد يُعاد الضبط، لذا استخدم زرّي **التنزيل/الرفع** في صفحة «تقدّمي» للاحتفاظ بتقدّمك ونقله.
